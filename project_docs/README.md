# Project Docs

## 현재 시스템 요약

- 분석 대상은 휘발유, 경유, LPG 전국 평균가입니다.
- 보조 지표는 WTI, Brent, 원/달러 환율, Google News/GDELT 뉴스 리스크입니다.
- 모델은 LSTM을 사용하되 최종 예측은 최근 국내 유가 추세, 환율, 뉴스 리스크, 일간 변동폭 제한을 함께 반영합니다.
- 웹 화면은 홈 대시보드(`/`), 커스텀 API 문서(`/docs`), 그래프 갤러리(`/graphs`)로 구성됩니다.
- 주요 산출물은 `oil_forecast_service/outputs`와 `oil_forecast_service/outputs/figures`에 저장됩니다.

## 문서 갱신 기준

코드 구조, API 경로, 산출 파일 이름, 데이터 출처가 바뀌면 이 폴더의 문서도 같이 갱신해야 합니다.
특히 유종 추가, 그래프 파일명 변경, 최신화 정책 변경은 보고서 내용과 직접 연결되므로 문서 누락이 없도록 확인합니다.
